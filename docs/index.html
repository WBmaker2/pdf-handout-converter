PDF Handout Converter

가로(landscape) 프레젠테이션 PDF를 A4 세로 유인물 형식 PDF로 변환하는 Python 도구입니다.

GitHub 저장소

실행 방법

python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python app.py

웹 UI: http://127.0.0.1:7860

기능

  • 2장 / 6장 배치 모드
  • 여러 PDF 동시 변환, 개별 또는 ZIP 다운로드
  • 벡터 보존 변환 (화질 손실 없음)
